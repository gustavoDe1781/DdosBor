```bash
pip install requests urllib3
```

# instalação em:
_termux_
```
pkg update
pkg upgrade
pkg install git
git clone https://github.com/gustavoDe1781/DdosBor.git
cd ddos.py
python ddos.py
```
# em windows:
```
pip install requests
python -m pip install --upgrade pip
python -m pip install requests
git clone https://github.com/gustavoDe1781/DdosBor
Executa:
python ddos.py
```
# em Kali Linux(em qualquer distro)
```
sudo apt update && sudo apt upgrade -y
Instala Python e pip (se não tiver):
sudo apt install python3 python3-pip -y
pip3 install requests
wget https://github.com/gustavoDe1781/DdosBor.git
chmod +x ddos.py
python3 ddos.py
ou python ddos.py
```
